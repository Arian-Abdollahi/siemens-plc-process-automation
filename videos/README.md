## Add a film

1. Use the suggested name for a short repository-hosted MP4, or keep the original film on a suitable video host.
2. Add the real file or hosted URL, then replace the matching pending entry in the root README with a watch link. For a file under `videos/`, the root README link points to that filename in this folder.
3. Update `catalog.json` with its actual repository path or video URL and set its status to `available`.
4. Include a short caption identifying the circuit/program version, inputs, and what the recording demonstrates. Keep pending entries for films that have not been uploaded.

Record the start condition, a complete cycle, relevant timer/sensor transitions, and stop/reset behavior where applicable. MP4/H.264 is a practical choice for browser playback. For a longer film, a hosted link keeps the Git history smaller.

GitHub's [attachment guidance](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files) covers supported media and upload limits. A hosted video link can be placed in the README; an embedded YouTube iframe is not a portable GitHub README solution. No empty or fabricated video files are included here.
